HOW THE HAMSTER SETS THE FEE

Before every swap the pool calls SqueekCore.state() and looks at the Squeek blocks settled since it last looked. No new work in that stretch → NAP. Work below workPerThousandBlocks → JOG. Work at or above it → ZOOMIES. Between settlements the last class sticks, so the on-chain tier lags the live cam by about one round. Every fee stays in the pool for LPs — no protocol cut, no owner, no fee switch. Last observation: —.
